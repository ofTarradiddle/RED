# REDI Play for iOS

A native SwiftUI investing game, with the existing ETF comparison tools alongside it.
The app opens on **Play**: $100 of fictional capital, 12 historical opportunities,
Classic and Daily runs, animated wing-H flight, haptic decisions, resumable games,
and replay-verified device scores. It works offline using bundled dated history
and the same JavaScriptCore accounting rules as the web game. No remote code or
web view powers the native game. Different modes, UTC days and data editions have
separate scoreboards; no public leaderboard or Game Center connection is claimed.

The Compare, Risk and REDI tabs provide a native interface for comparing the Hetzerk Innovation Factor ETF with SPY,
VOO, QQQ, ITAN, and SYLD. Requires iOS 17 or later. It uses Swift Charts, native
tabs, touch chart inspection, saved comparisons, and the iOS share sheet. There
is no embedded website, login, analytics SDK, or brokerage connection.

## Open and run

Open `REDICompare.xcodeproj` in full Xcode, choose the shared **REDICompare**
scheme, and run on an iPhone simulator. Use Xcode 26.3 for parity with CI.
Apple Command Line Tools alone cannot build an iOS app.

The Xcode project is generated by `python3 ios/generate_project.py`. If changing
targets or project settings, edit the generator and regenerate the project.

## Data and calculations

The game bundles `data/innovation/dataset.json` and both innovation engines via
project references, so the sources cannot silently drift into a separate copy.
Updating the app publishes a new game-data edition when economic inputs change.
Only canonical allocation choices are saved; balances are replayed on restore.

The comparison tools download the daily public JSON snapshot at
`https://oftarradiddle.github.io/RED/compare/data.json`. The existing GitHub
Actions data publisher refreshes Yahoo peer observations on weekdays. Pull to
refresh checks for the latest published snapshot; it does not query a live quote
stream. Source dates and unavailable data remain visible.

REDI is explicitly illustrative until the publisher receives approved live fund
data. Only public comparison data enters this app; private shadow accounting,
blotters, and credentials are not bundled. The debug UI-test fixture is excluded
from Release archives and is never used as a fallback for live network errors.

The last validated snapshot is cached atomically on the device. A failed refresh
keeps that snapshot and displays its age. Comparison preferences and up to 20
named comparisons stay in local UserDefaults. Sharing occurs only through the
user's chosen iOS share destination. See `REDICore/README.md` for calculation
definitions, reinvestment assumptions, and missing-data behavior.

## Checks and review builds

```sh
swift test --package-path ios/REDICore
xcodebuild test -project ios/REDICompare.xcodeproj -scheme REDICompare \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' CODE_SIGNING_ALLOWED=NO
```

`.github/workflows/native-ios.yml` selects an available iPhone simulator, runs
the calculation and interaction tests, exports native screenshots, and archives
the device app. Its `redi-native-review` artifact contains an **unsigned**
archive for review. It cannot be installed from the App Store or on a physical
iPhone until signing and distribution are configured.

## TestFlight and App Store

1. Enroll or use the publisher's Apple Developer Program account; select its
   signing team in Xcode. Confirm or replace the proposed bundle identifier
   `com.hetzerk.REDIPlay` in the project generator.
2. Register the app in App Store Connect. Review the metadata draft in
   `AppStore/metadata.md`, privacy disclosure, market-data distribution rights,
   and the eventual live REDI feed before a public financial-app release.
3. Archive the Release scheme for a generic iOS device with the authorized team,
   then use Organizer → Distribute App → App Store Connect. No signing secrets
   belong in this repository.
4. Distribute a development build through TestFlight; submit the final public
   build and its screenshots to App Review when ready.

The yellow development notice remains in this development version. The current
prototype is not represented as an approved or published App Store product.

Apple references: [upload builds](https://developer.apple.com/help/app-store-connect/manage-builds/upload-builds/),
[TestFlight](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/).
