# Reference implementations

The files here are superseded and are not served or copied into the public build.

- `site/` preserves the previous hand-authored pages, with the requested brand replacement. Old performance, offering, registration and tax claims are unverified historical demo copy, not approved disclosures.
- `next/` is the incomplete former Next.js implementation. It is not the local review site.
- `scripts/` contains the old disconnected data generators/API. Use `python3 -m publishing.build` with `workbooks/hetzerk-demo.xlsx` instead.

Original demo JSON remains under `etfs/*/data/` as input to the deterministic demo seed generator. It is not published. Only `dist/` is public.
